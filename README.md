## Final Project for CS188 - MIPS Assembly Code Editor

### Overview: 
We are making a web based MIPS Assembly code editor and compiler. This app is for people not
familiar with assembly or who don't have a compiler to easily run simple sections of Assembly code.
People will also be able to save their code in the cloud to access it anywhere without having to save it
locally every time. It will also be at least compatible with mobile devices.

Features are below: 

### Core features
- Compile MIPS code
- Output to console
- Editor in browser
- Save files to user
- User registration
### Basic features
- upload/download files
- See registers
- See RAM/ROM
- Show ads
- Auto logout
### Stretch features
- Share button
- Friends
- public projects that you can scroll through
- directories of projects
